# Basics

This page lives in a **subfolder** (`Guides/`). Subfolders are mirrored in the sidebar,
and `[[Basics]]` resolves to it from anywhere.

A short line of math: $2 + 2 = 4$.

## Two kinds of links

1. **Wiki links** — `[[Home]]`, `[[Advanced]]`, or with an alias `[[Basics|back to me]]`.
2. **Markdown links** — a relative file link like [`Advanced.md`](Advanced.md).

```js
// this file is the frame's logic
function hello() {
  return "no server, no network";
}
```

> [!TIP]
> Wiki links work from any folder — `[[Advanced]]` resolves from here.
